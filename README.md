# candidates-web

Pantalla de consulta de **Candidates** de TalentHub, hecha con React, TypeScript y Vite.
Por ahora trabaja con datos locales (todavía no llama a la API).

## Qué incluye
- Cabecera, buscador (por nombre o ciudad) y cuadrícula de tarjetas.
- Contador de resultados y mensaje cuando no hay coincidencias.
- Favoritos: el estado vive en la página, así que se conserva al filtrar.

## Cómo ejecutarlo
```
npm install
npm run dev
```

## Comandos
- `npm run dev`: servidor de desarrollo
- `npm run build`: compilación para producción
- `npm run lint`: revisión de código
